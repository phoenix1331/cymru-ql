# Data sources and credits

| Data | Source | Licence |
|---|---|---|
| Clubs, grounds, coordinates, divisions, capacities, opened years, nicknames, colours, ground descriptions | Over the Terraces Cymru config (same author), reconciled against Wikipedia club and ground articles and the Cymru North / Cymru South member-club tables | Original compilation |
| Gap filling (address, capacity, opened year, founded year) | [Wikidata](https://www.wikidata.org) via SPARQL | CC0 1.0 |
| Gap filling fallback (address) | [OpenStreetMap](https://www.openstreetmap.org/copyright) contributors | ODbL 1.0, attribution required |
| League membership by season | Wikipedia season articles for the Cymru Premier, Cymru North and Cymru South | CC BY-SA 4.0, credited here |
| Road distances | [OSRM](https://project-osrm.org) public demo server, computed once offline from OpenStreetMap data | ODbL 1.0 (underlying OpenStreetMap data) |
| Straight-line distances | Calculated (haversine) from ground coordinates | n/a |
| Fixtures and results | Simulated | n/a |
| Crests | Generated placeholders | n/a |

No club badges, sponsor logos or league marks are included.

This is a hobby project with no connection to the Football Association of Wales, the Cymru Leagues or any club.

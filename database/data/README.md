# Seed data

Committed JSON read by the database seeders. Generated by `php artisan cymru:import` where noted; edit by hand only where noted.

| File | Shape | Source |
|---|---|---|
| `leagues.json` | `[{slug, name, tier, region}]` | Hand-maintained |
| `seasons.json` | `[{slug, name, starts_on, ends_on, is_current}]` | Hand-maintained |
| `grounds.json` | `[{slug, name, town, lat, lng, capacity, opened, address, description}]` | `cymru:import`, enriched by `--enrich` |
| `clubs.json` | `[{slug, name, ground, colour, nickname, founded}]` | `cymru:import` (`ground` is a ground slug) |
| `club_seasons.json` | `[{club, season, league, position}]` | `cymru:import` (slugs; `position` is the final league position, null while a season is in progress) |
| `distances.json` | `{generated_at, source, grounds: [slug], road_km: [[float]], straight_km: [[float]]}` | `cymru:import --distances` (matrix rows and columns follow `grounds` order) |

Slugs are the join keys between files. Club slugs match Over the Terraces so the data can be shared. Ground slugs combine the ground name and town (e.g. `the-oval-caernarfon`) because some ground names repeat across Wales.

See `SOURCES.md` for data sources and licences.
